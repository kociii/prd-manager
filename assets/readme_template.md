## 维护规则

- 新增版本时：插入到“当前版本”区域最上方
- 扩展版本时：同步更新对应摘要、状态、日期和文档链接
- 归档版本时：从“当前版本”移至“已归档”区域
- 只链接实际存在的产物，design.md 可附 #页面ID 定位；不把模板中的全套链接直接复制为结果
- 状态只用统一枚举：草案/待评审/已确认/开发中/已验收/已发布/已取代/已取消/已归档，须与 prd.md 头部一致（见 references/lifecycle.md）
- 项目若用到 S/F/Q/D/T/V/I/TC 以外的 ID 前缀，在此登记，避免与 P0/P1 优先级冲突
- 始终保持语义化版本倒序排列：最新版本在最上方
