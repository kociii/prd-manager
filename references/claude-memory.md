# 项目记忆与架构决策

使用项目已有入口（如 CLAUDE.md），保留其有效约定；不创建互相矛盾的第二套规则。需要新建时使用 `assets/claude_template.md`。

记忆记录稳定事实与“为什么”：真实技术栈、文档/代码入口、已确认约定、ADR、已知问题。需求细节链接 prd.md，页面链接 design.md#页面ID，实现细节链接 dev.md，检查记录链接 test/review；不要复制完整文档。

更新时机是用户请求、新的持久决策、项目约定改变或有复用价值的事故结论。例子中的测试命令、覆盖率数字、数据库或目录不得直接变成项目规则。已解决问题注明状态，不永远当作当前风险。

ADR 保留背景、决策、理由、影响、状态、日期和依据。若只是待评估方案，标注提议，不写成已采纳。
