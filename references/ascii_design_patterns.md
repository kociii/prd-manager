# ASCII 线框规范与模式

## 表达边界

ASCII 用于说明页面区域、内容优先级和控件位置；图外的元素/状态/视觉规格补足行为与像素信息。字符宽度不是 CSS px。正式稿不能只有“内容区”“按钮1”，应使用与需求一致的内容和动作。

默认每个版本一个 design.md，多个页面按稳定 ID 分节。不要把多个业务页面揉成一张无限宽图。

## 排版约定

1. **围栏**：线框使用标为 `ascii` 的 fenced code block，保证等宽显示；流程图可用 Mermaid，不与线框混用。
2. **边框**：新稿统一采用 `+`、`-`、`|`。已有 Unicode 盒线稿可保留风格，但同一个图不混用两套边框；本 skill 的校验器只检查新规范。
3. **显示宽度**：ASCII 字符按 1 列，中文与东亚宽字符按 2 列，组合附加符不另占列。使用空格，不用 Tab、全角空格、Emoji、制表/方向控制符或装饰图标凑对齐；中文图标改文字标签。
4. **统一行宽**：同一外框每行显示宽度相同，上下边框长度相同。嵌套分栏的连接点与竖线手动核对；不要按字符串字符数补空格。
5. **尺度**：桌面建议 72–100 显示列，移动端建议 32–44 列；超过 120 列时优先拆图或简化。按需求调整，避免为了限制宽度隐藏重要业务字段。
6. **长内容**：换行优先于截断；确需截断在图内用 `...`，图外说明省略、展开或完整查看方式。列表可画 2–3 行示例，同时保留实际分页/滚动规则。
7. **图注放图外**：图上方写页面 ID、视口、状态、版本变化。滚动/固定/布局比例用图注或规格说明，不用不同空格暗示精确尺寸。
8. **密度**：有意义的分隔即可，避免多层大盒子和大片空行；同类页面重复框架可引用公共布局。

不同 Markdown 阅读器/等宽字体可能对个别 Unicode 字符宽度处理不同。边框使用基础 ASCII、避免 Emoji，可减少差异；最终在目标阅读器抽查。

## 控件符号

| 记法 | 含义 | 说明 |
|------|------|------|
| `[C01 保存*]` | 主行动按钮 | 星号是规格标记，不是产品文案 |
| `[C02 取消]` | 普通/次行动按钮 | 主次关系在元素表确认 |
| `[C03 保存] (disabled)` | 禁用按钮 | 表中写禁用原因、启用条件 |
| `C04 姓名(必填): [________]` | 输入框 | 标签持久可见，填写校验与错误反馈 |
| `C05 状态: [全部 v]` | 选择器 | 选项、默认值、是否多选写入表格 |
| `[ ] C06 同意条款` / `[x]` | 复选框 | 不用按钮外观代替其语义 |
| `( ) C07 选项` / `(*)` | 单选项 | 标明同组关系与默认选择 |
| `< C08 返回列表` | 链接/返回 | 明确目标页面及保留状态 |
| `> 订单管理` | 当前导航项 | 非激活项正常文字，激活不可只靠颜色 |
| `...` | 省略内容 | 仅在正文注明省略规则后使用 |

Cxx 的组件定义在页内唯一，重复行共用定义，以业务键区分实例；跨页引用写完整的 Pxx/Cxx。关键区域用 Rxx，与组件层级树对应。重要交互控件分配 ID；重复列表项可共享组件定义并说明行数据参数，不给每个静态文本机械编号。

## 页面和状态标注

示例：`页面 D01-orders · 桌面 1440px · default · 本版修改筛选区`。视口值来自目标设备/现有规则，图的显示列数只是排版。

同页异常状态推荐标题 `### empty`、`### error`、`### submitting` 等。复杂状态补局部线框并注明替换区域；不能把局部弹窗误标成新页面。结构变化大的移动端补独立线框，避免把桌面图压窄后宣布已适配。

## 模式示例（业务数据仅作示范）

### 1. 查询与表格

适合需按字段比较的记录。查询重置、翻页、行操作及选择保留规则写入交互表。

```ascii
+--------------------------------------------------------------------------+
| 订单管理 / 订单列表                         [C01 新建订单*]              |
+--------------------------------------------------------------------------+
| [C02 订单号: ____________]  [C03 状态: 全部 v]                           |
| [C04 查询]  [C05 重置]                                                   |
| 已选 0 项；批量操作仅在选中后显示。                                      |
+--------------------------------------------------------------------------+
| 订单号      客户      状态      金额          操作                       |
| OD-001      林女士    待付款    398.00        [C06 详情]                 |
| OD-002      陈先生    已完成    268.00        [C06 详情]                 |
+--------------------------------------------------------------------------+
| 共 26 条 / 每页 10 条                  [上一页] 1/3 [下一页]             |
+--------------------------------------------------------------------------+
```

### 2. 主从分栏

适合连续查看/处理对象。图外注明左栏宽度与右栏弹性；窄屏转独立详情时写出返回后选中项和滚动位置。

```ascii
+----------------------+--------------------------------------------------------+
| 订单列表             | OD-001 / 林女士                        [C02 编辑*]     |
| [C01 搜索: ____]     |                                                        |
|                      | 服务: 全屋深度清洁                                     |
| > OD-001 林女士      | 金额: 398.00 元                                        |
|   OD-002 陈先生      | 状态: 待服务                                           |
|   OD-003 周女士      |                                                        |
|                      | [C03 查看进度]  [C04 返回列表]                         |
+----------------------+--------------------------------------------------------+
```

### 3. 分组表单

用分组表达业务关系，避免对简单表单强行加步骤。校验失败通常在字段下方展示，提交中保留输入。

```ascii
+--------------------------------------------------------------------------+
| 新建服务预约                                                             |
+--------------------------------------------------------------------------+
| 基本信息                                                                 |
| C01 联系人(必填): [____________________]                                 |
| C02 手机号(必填): [____________________]                                 |
| 示例: 13800000000；只用于联系预约。                                      |
|                                                                          |
| 预约信息                                                                 |
| C03 服务类型: [全屋清洁 v]                                               |
| C04 服务日期: [2026-09-23 v]                                             |
| C05 备注: [___________________________]                                  |
|           [___________________________]                                  |
+--------------------------------------------------------------------------+
| [C06 取消]                                     [C07 保存*]               |
+--------------------------------------------------------------------------+
```

### 4. 手机详情

先展示状态和决定行动的信息，再展开辅助详情。固定底栏与软键盘/安全区的关系需用文字定义。

```ascii
+------------------------------------+
| < C01 返回       订单详情          |
+------------------------------------+
| OD-001 / 待付款                    |
| 全屋清洁服务                       |
| 金额: 398.00 元                    |
+------------------------------------+
| 联系人: 林女士                     |
| 时间: 09-23 09:00                  |
| 地址: 示例小区 2 栋 601 室         |
| 备注: 到达前 15 分钟联系           |
+------------------------------------+
| 主体可滚动；下方操作固定。         |
| [C02 取消订单]  [C03 去付款*]      |
+------------------------------------+
```

### 5. 确认弹窗（局部覆盖层）

与原页面关联，说明打开条件、焦点进入、背景是否可操作、关闭后返回位置及失败恢复。取消订单规则仅为示例，按项目确认的业务定义填写。

```ascii
+------------------------------------------------------------------+
| 取消订单                                           [C03 关闭]    |
+------------------------------------------------------------------+
| 确认取消 OD-001 的预约？                                         |
| 取消后将释放当前时段，请先确认不再需要本次服务。                 |
|                                                                  |
| C01 取消原因(必填): [请选择原因 v]                               |
+------------------------------------------------------------------+
| [C02 保留订单]                                 [C04 确认取消*]   |
+------------------------------------------------------------------+
```

### 6. 无搜索结果（替换结果区）

不等同于首次无数据；清除筛选应有真实去向。

```ascii
+--------------------------------------------------------------+
| 搜索结果 / 共 0 条                                           |
+--------------------------------------------------------------+
| 未找到符合条件的订单                                         |
| 请检查订单号，或清除当前筛选条件。                           |
|                                                              |
| [C01 清除筛选*]                                              |
+--------------------------------------------------------------+
```

### 7. 运营概况

指标需支持判断或下一步操作；图表口径、空值和时间维度在元素表中定义，不把 ASCII 当作精确图表。

```ascii
+--------------------------------------------------------------------------+
| 运营概况 / 本周                            [C01 时间: 本周 v]            |
+--------------------------------------------------------------------------+
| 本周订单 128       待处理 8       按时完成率 96%                         |
| 统计口径: 本周已创建订单；指标可进入对应筛选列表。                       |
+--------------------------------------------------------------------------+
| 趋势区: 按天展示订单数量；缺失日期显示无数据。                           |
| 具体图表类型和坐标口径见元素表。                                         |
+--------------------------------------------------------------------------+
| 优先处理                                                                 |
| OD-001  待确认服务时间                       [C02 处理*]                 |
| OD-008  联系信息不完整                       [C03 补充]                  |
+--------------------------------------------------------------------------+
```

## 配套层级树

每个页面的线框后附 `text` 围栏层级树：页面 Pxx → 区域 Rxx → 组件 → 控件 Cxx。树采用 `├──` / `└──` 等连接符即可，不套线框的等行宽规则。子节点体现实际包含；重复、条件显示、覆盖层和复用关系以节点注释表达。

图上区域和交互控件必须能在树或映射表中定位，反过来树中的可见节点也应能定位到线框/状态说明。树下补职责、输入、状态归属和事件关系；详细规则见 `references/design-guidance.md`。

## 检查

运行 `python3 <skill-dir>/scripts/validate_ascii.py <design.md>`，检查新规范的 ascii 围栏块。只读检查，不自动改写页面或文案；发现错位按显示列数修复。

脚本不判断信息架构、交互闭环、响应式或视觉合理性，这些按 `references/design-guidance.md` 复核。未出现 ascii 围栏时会报告缺少可检查图，而非虚报全部通过。
