# 旧格式文档迁移

适用：项目里已有 `docs/prd/` 文档，缺少 front matter、`skill_version`、统一状态枚举，或 CHANGELOG 分散在版本目录。

1. **只读盘点**：读 README 与各版本 prd.md 头部，列出差异清单（状态词与枚举对照、缺失字段、ID 前缀冲突、待决问题是否有状态/决定/日期、CHANGELOG 位置）。不修改任何文件。
2. **征求同意**：把差异清单与拟做的改动给使用人，确认范围后再动手。
3. **增量补字段**：沿用「不覆盖用户修改」。仅添加 front matter、状态映射、缺失表列；不重写正文、不重编号。
4. **状态映射**：草案/规划中/待评审→相应枚举；已完成/已上线→「已发布」（须在 CHANGELOG 有带日期条目，否则问使用人）；验收中→「开发中」或「已验收」按证据判断。
5. **CHANGELOG 合并**：版本目录下的 CHANGELOG.md 内容并入 `docs/prd/CHANGELOG.md`，按版本倒序；原文件不删除，除非使用人明确要求。
6. **ID 前缀冲突**：只登记与报告，改名由使用人决定。
7. 完成后运行 `scripts/check_docs.py` 并报告剩余 WARNING。
